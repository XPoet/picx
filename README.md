**PicX，免费、安全的一站式在线图片处理平台。**

从 GitHub 图床出发，PicX 现已升级改造，集图片压缩、图片裁剪、格式转换、图片水印、宫格切图、图片标记与图片拼接于一体。无论是日常修图、内容创作，还是图片托管，打开浏览器就能开始。

**[立即使用](https://picx.xpoet.cn) · [GitHub 图床](https://picx.xpoet.cn/images-hosting/) · [图床文档](https://picx-docs.xpoet.cn)**

[![home](docs/images/home.png)](https://picx.xpoet.cn)

## 为什么选择 PicX

- **打开即用**：无需下载安装，在浏览器里就能完成常用图片处理。
- **隐私优先**：图片工具在本地浏览器中运行，处理图片无需上传服务器。
- **简单顺手**：拖拽、粘贴或选择图片，调整参数、预览效果，下载作品。

## 图片工具

| 工具     | 能做什么                               |
| -------- | -------------------------------------- |
| 图片压缩 | 批量减小图片体积，按需调整质量         |
| 图片裁剪 | 裁掉多余区域，留下想要的画面           |
| 格式转换 | 转换图片格式，适配不同使用场景         |
| 图片水印 | 添加文字或图片水印，支持单个与全屏布局 |
| 宫格切图 | 将图片切分为宫格，方便社交平台分享     |
| 图片标记 | 标注图片重点，让截图说明更清楚         |
| 图片拼接 | 将多张图片合成一张，方便展示与分享     |

> 复杂的交给 PicX，简单的留给你。

## GitHub 图床

熟悉的图床服务依然保留，基于 GitHub API，将图片托管到你的 GitHub 仓库，支持目录管理、批量操作，以及一键复制 Markdown / HTML / BBCode 等格式的图片链接。

通过 GitHub OAuth 或 Token 登录，完成图床配置即可使用。查看 [图床使用指南](https://picx-docs.xpoet.cn/usage-guide/get-start.html)，或直接 [进入图床](https://picx.xpoet.cn/images-hosting/)。
