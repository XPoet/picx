**PicX, a free and secure online platform for all your image editing needs.**

Originally built for GitHub image hosting, PicX has evolved into a complete toolkit for image compression, cropping, format conversion, watermarking, grid splitting, annotation, and stitching. Whether you are editing everyday photos, creating content, or hosting images, just open your browser to get started.

**[Try PicX](https://picx.xpoet.cn) · [GitHub Image Hosting](https://picx.xpoet.cn/images-hosting/) · [Image Hosting Docs](https://picx-docs.xpoet.cn)**

[![PicX home page](images/home.png)](https://picx.xpoet.cn)

## Why PicX

- **Ready to use**: Handle common image editing tasks in your browser, with no downloads or installation.
- **Privacy first**: Image tools run locally in your browser. There is no need to upload images to a server for processing.
- **Easy to use**: Drag, paste, or select images, adjust settings, preview the results, and download your work.

## Image Tools

| Tool              | What it does                                                     |
| ----------------- | ---------------------------------------------------------------- |
| Image Compression | Reduce image file sizes in batches with adjustable quality       |
| Image Cropping    | Remove unwanted areas and keep the parts you need                 |
| Format Conversion | Convert images to suit different use cases                       |
| Image Watermarks  | Add text or image watermarks, placed once or across the image     |
| Grid Splitting    | Split an image into a grid of tiles for sharing on social media   |
| Image Annotation  | Highlight key details to make screenshots easier to explain       |
| Image Stitching   | Combine multiple images into one for easy presentation and sharing |

> Let PicX handle the complexity so you can keep things simple.

## GitHub Image Hosting

The familiar image hosting service is still available. Using the GitHub API, PicX hosts images in your own GitHub repository, with directory management, batch operations, and one-click copying of image links in Markdown, HTML, BBCode, and other formats.

Sign in with GitHub OAuth or a Token, then configure image hosting to get started. Read the [image hosting guide](https://picx-docs.xpoet.cn/usage-guide/get-start.html) or [open image hosting](https://picx.xpoet.cn/images-hosting/).
