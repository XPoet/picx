**PicX，免費、安全的一站式線上圖片處理平台。**

從 GitHub 圖床出發，PicX 現已升級改造，集圖片壓縮、圖片裁切、格式轉換、圖片浮水印、宮格切圖、圖片標記與圖片拼接於一體。無論是日常修圖、內容創作，還是圖片託管，打開瀏覽器就能開始。

**[立即使用](https://picx.xpoet.cn) · [GitHub 圖床](https://picx.xpoet.cn/images-hosting/) · [圖床文件](https://picx-docs.xpoet.cn)**

[![PicX 首頁](images/home.png)](https://picx.xpoet.cn)

## 為什麼選擇 PicX

- **開啟即用**：無需下載安裝，在瀏覽器裡就能完成常用圖片處理。
- **隱私優先**：圖片工具在本機瀏覽器中執行，處理圖片無需上傳伺服器。
- **簡單順手**：拖曳、貼上或選擇圖片，調整參數、預覽效果，下載作品。

## 圖片工具

| 工具       | 能做什麼                                 |
| ---------- | ---------------------------------------- |
| 圖片壓縮   | 批次縮小圖片檔案大小，依需求調整品質       |
| 圖片裁切   | 裁掉多餘區域，留下想要的畫面               |
| 格式轉換   | 轉換圖片格式，適用於不同使用情境           |
| 圖片浮水印 | 加入文字或圖片浮水印，支援單個與全畫面配置 |
| 宮格切圖   | 將圖片切分為宮格，方便在社群平台分享       |
| 圖片標記   | 標註圖片重點，讓螢幕截圖說明更清楚         |
| 圖片拼接   | 將多張圖片合成一張，方便展示與分享         |

> 複雜的交給 PicX，簡單的留給你。

## GitHub 圖床

熟悉的圖床服務依然保留，透過 GitHub API，將圖片託管到你的 GitHub 儲存庫，支援目錄管理、批次操作，以及一鍵複製 Markdown / HTML / BBCode 等格式的圖片連結。

透過 GitHub OAuth 或 Token 登入，完成圖床設定即可使用。查看 [圖床使用指南](https://picx-docs.xpoet.cn/usage-guide/get-start.html)，或直接 [進入圖床](https://picx.xpoet.cn/images-hosting/)。
